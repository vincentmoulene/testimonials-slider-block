Un panneau « À vendre » donne un numéro de téléphone. Le passant note le numéro, ou plus probablement ne le note pas. Avec un QR code, il voit les photos, le prix, la surface et le DPE avant même de vous appeler — et quand il appelle, il sait déjà ce qu'il veut.

## Le panneau : qualifier avant le premier appel

Le code doit ouvrir **l'annonce de ce bien**, pas le site de l'agence. Photos, prix, surface, diagnostics, plan. Le prospect qui appelle ensuite a franchi le premier filtre tout seul.

Contraintes pratiques du panneau :

- On scanne depuis le trottoir, souvent depuis une voiture arrêtée : comptez **15 cm de large minimum** pour un scan à 1,5 m, davantage si le panneau est en hauteur.
- Le panneau reste dehors des mois : impression résistante aux UV, sinon le contraste s'efface et le code meurt.
- Prévoyez le cas « bien vendu » : votre page doit alors afficher « vendu » et proposer les biens similaires, pas une erreur 404.

## La vitrine de l'agence

Le vrai moment, c'est le dimanche : l'agence est fermée, les gens regardent quand même. Un code par annonce en vitrine, ou un code unique vers les biens du secteur, capte une audience qui n'aurait rien fait d'autre.

## Le dossier de location

Un code sur l'annonce qui ouvre la liste des pièces à fournir et le formulaire de candidature. Vous recevez des dossiers complets au lieu de vingt e-mails avec des pièces manquantes.

## L'état des lieux et la gestion

Peu spectaculaire, très utile :

- Un code dans le compteur ou le local technique, qui ouvre la fiche de l'équipement, la date du dernier entretien et le contact du prestataire.
- Un code dans le logement de location saisonnière qui ouvre le guide d'accueil.
- Un code sur le tableau d'affichage de la copropriété, vers les comptes rendus d'assemblée.

## Trois erreurs qui coûtent des contacts

1. **Renvoyer vers la page d'accueil de l'agence.** Le prospect voulait ce bien-là, il ne cherchera pas dans une liste de deux cents annonces.
2. **Encoder une URL avec une référence interne** du type `?ref=A12345&session=…`. Elle change au prochain changement de logiciel, et le code imprimé meurt avec elle.
3. **Oublier le suivi.** Ajoutez `?utm_source=panneau` : au bout d'un trimestre, vous savez si les panneaux valent leur coût.

## Ce qu'il faut retenir

En immobilier, le QR code ne fait pas vendre : il supprime le délai entre l'intérêt et l'information. Or dans ce métier, le délai est exactement ce qui fait perdre les contacts.
