Un voyageur qui arrive pose toujours les mêmes vingt questions : le code Wi-Fi, l'heure du petit-déjeuner, comment marche le chauffage, où sortir les poubelles, où manger le soir. Vous y répondez individuellement, ou vous les affichez une fois pour toutes.

## Le code Wi-Fi : celui qui sert dès la première minute

C'est la première chose que cherche un voyageur, avant même de poser sa valise. Un code Wi-Fi plastifié sur le bureau supprime la dictée du mot de passe — depuis iOS 11 et Android 10, le téléphone propose la connexion directement.

Utilisez le réseau invité de votre box, pas celui de votre ordinateur ou de vos caméras. Et si vous changez le mot de passe, régénérez et réimprimez le même jour : le code imprimé contient l'ancien.

## Le livret d'accueil : là où le QR code change vraiment la vie

Un classeur papier est périmé dès qu'un restaurant ferme, et personne ne le relit. Une page web derrière un QR code se met à jour en trente secondes, s'affiche dans la langue du téléphone, et contient ce qu'un classeur ne peut pas contenir : une vidéo de trente secondes montrant comment allumer la plaque à induction ou fermer le volet capricieux.

Ce qu'il faut y mettre :

- Wi-Fi, chauffage, électroménager, télévision
- Heures d'arrivée et de départ, tri des déchets, consignes de départ
- Vos recommandations : les trois restaurants, la boulangerie, le marché, la pharmacie de garde
- Le numéro à appeler en cas de problème

## Les autres codes qui gagnent leur place

- **Sur la porte** : le code d'itinéraire jusqu'à l'entrée exacte — pas jusqu'au centre du village. C'est ce qui évite l'appel à 22 h « on ne trouve pas ».
- **Dans la chambre** : le service en chambre, le spa, le room service, la note.
- **Au départ** : le code d'avis, affiché la veille du départ ou glissé dans la facture, quand le séjour s'est bien passé.
- **Sur l'équipement** : un code sur la chaudière ou le lave-linge vers la notice et le contact du dépanneur — pour vous, pas pour le client.

## Trois erreurs fréquentes

1. **Le code sous plastique brillant, sous un spot.** Les reflets tuent le scan. Testez le soir, lumière allumée.
2. **Un livret en PDF.** Illisible sur un téléphone. Une page web simple, toujours.
3. **Un seul code pour tout.** Wi-Fi et livret d'accueil sont deux besoins, à deux moments différents. Deux codes, deux étiquettes claires.

## Ce qu'il faut retenir

Le Wi-Fi rend service dès la première minute ; le livret d'accueil, lui, vous fait gagner des heures sur la saison et supprime la moitié des messages. Commencez par ces deux-là, le reste est du bonus.
