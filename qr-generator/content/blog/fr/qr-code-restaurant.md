Le QR code est entré dans les restaurants par la porte du menu sans contact. C'est dommage, parce que le menu est justement l'usage le plus souvent mal fait — et les quatre autres, eux, rapportent tous les jours.

## 1. Le menu — à condition de ne pas envoyer un PDF

Un PDF de menu sur un téléphone, c'est un document A4 qu'il faut zoomer, déplacer, re-zoomer. Le client abandonne et redemande la carte papier : vous avez ajouté une étape, pas supprimé une corvée.

Ce qui fonctionne : une **page web simple**, lisible sans zoom, catégories en haut. Pas d'application, pas de compte, pas de bannière cookies qui couvre l'écran. Et gardez quelques cartes papier : une partie de votre clientèle ne scannera jamais, et c'est très bien.

Point critique : **l'adresse du menu ne doit jamais changer**. Si vous réimprimez les chevalets à chaque changement de carte, vous avez perdu. Publiez sur une URL stable (`votre-restaurant.fr/carte`) et modifiez le contenu derrière.

## 2. La commande et le paiement à table

C'est là que le gain est réel : en terrasse aux heures de pointe, un code par table qui ouvre la commande fait tomber le temps d'attente et les allers-retours. Même chose pour l'addition — le client paie et part sans chercher le serveur du regard pendant dix minutes.

Le code doit alors identifier la table (`/commander?table=12`), donc un code différent par table. Prévoyez-les plastifiés et numérotés au dos : un chevalet déplacé fausse toutes les commandes.

## 3. Les avis — le meilleur retour sur investissement

Un client content ne laisse presque jamais d'avis, non par mauvaise volonté mais parce que c'est trop long : ouvrir Maps, chercher le bon établissement, faire défiler, noter. Un code qui ouvre directement le formulaire d'étoiles supprime les quatre étapes.

Le moment compte plus que l'emplacement : sur l'addition, à la fin du repas, quand le client est encore là et satisfait. Pas dans un e-mail trois jours plus tard.

Une règle absolue : **montrez le même code à tout le monde**. Filtrer selon la note attendue est contraire aux règles de Google et fait suspendre des fiches.

## 4. Le Wi-Fi client

Un code Wi-Fi collé sur le chevalet évite de dicter vingt caractères dix fois par service. Depuis iOS 11 et Android 10, le téléphone propose la connexion directement depuis l'appareil photo. Utilisez le réseau invité de votre box, pas celui de la caisse.

## 5. Fidélité, réservation, réseaux sociaux

Un code sur la carte de fidélité, sur le flyer glissé dans le sac de la vente à emporter, dans la vitrine pour réserver quand c'est fermé. Petits volumes, coût nul.

## Les quatre erreurs qui reviennent toujours

1. **Un code trop petit.** Sur une table, on scanne à 30-40 cm : 3 cm de large minimum, 5 cm c'est mieux.
2. **Un code sur fond sombre ou coloré.** Les lecteurs attendent du sombre sur du clair. Un rectangle blanc derrière le code coûte moins cher qu'un client perdu.
3. **Aucune indication.** Ajoutez une ligne : « Scannez pour voir la carte ». Tout le monde ne devine pas.
4. **Un code jamais testé sur place.** Testez-le dans votre salle, avec l'éclairage du soir, avec un iPhone et un Android, à la distance réelle. Cinq minutes, une fois.

## Ce qu'il faut retenir

Le menu est l'usage le plus visible et le moins rentable. Les avis et la commande à table, eux, se voient dans le chiffre. Commencez par ceux-là.
