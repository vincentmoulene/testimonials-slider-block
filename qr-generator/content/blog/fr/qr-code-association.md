Une association a peu de moyens techniques, beaucoup de supports papier et un problème constant : transformer une intention en action avant que la personne ne rentre chez elle et oublie.

## Le don : douze secondes au lieu de trois jours

Sur une affiche, dans un journal de quartier, sur un stand de marché : un code qui ouvre la page de don, avec le montant déjà prérempli si vous en suggérez un.

Deux façons de faire, très différentes :

**Le lien vers une page de don.** Simple, connu, mais chaque paiement par carte coûte des frais de commission — 1,5 à 3 % qui ne financeront pas votre projet.

**Le QR code de virement SEPA (GiroCode).** Le donateur scanne depuis son application bancaire, qui s'ouvre avec votre IBAN, votre nom et le montant déjà remplis. Il valide. **Zéro commission**, l'argent arrive directement sur le compte de l'association. C'est particulièrement bien lu par les applications bancaires allemandes, autrichiennes, néerlandaises et belges, et de plus en plus par les françaises.

Pour une association, la seconde option mérite d'être testée : sur 10 000 € de dons annuels, la différence n'est pas symbolique.

## L'adhésion et le renouvellement

Le renouvellement d'adhésion est le moment où l'on perd des membres, non par désaffection mais par oubli. Un code sur le bulletin, sur l'affiche de la salle, en bas du courrier de relance : le formulaire s'ouvre, l'adhésion se règle, c'est fait.

## Le bénévolat

Un code sur le stand du forum des associations, qui ouvre le formulaire d'inscription bénévole. Le passant intéressé ne repart pas avec un flyer qu'il perdra : il est déjà dans votre liste.

## Les usages internes qu'on oublie

- **L'assemblée générale** : un code sur la convocation vers les documents préparatoires ; un autre dans la salle pour le vote ou l'émargement.
- **Le matériel** : un code sur chaque équipement prêté (sono, tables, barnum) vers la fiche de réservation et l'état du matériel.
- **Les archives** : un code sur le classeur physique vers la version numérisée.

## Deux conseils de terrain

1. **Écrivez ce qu'il y a derrière.** « Scannez pour faire un don de 10 € » convertit largement mieux que « Scannez-nous ». La promesse doit être visible sans scanner.
2. **Gardez toujours une alternative papier.** Une partie de vos donateurs a soixante-quinze ans et ne scannera jamais. Le QR code ajoute un canal, il n'en remplace aucun.

## Ce qu'il faut retenir

Pour une association, le QR code coûte zéro et supprime le délai entre l'émotion et le geste. C'est exactement là que se perdent les dons.
