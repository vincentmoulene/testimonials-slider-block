Un événement, c'est un lieu où plusieurs centaines de personnes ont besoin de la même information en même temps, sans réseau fiable. C'est exactement le terrain du QR code — à condition d'anticiper le jour J.

## Le billet : le contrôle d'accès

Un code unique par billet, scanné à l'entrée, marqué comme utilisé. C'est ce qui empêche la revente du même billet à trois personnes.

Deux règles vitales :

- **Prévoyez le mode hors ligne.** Une salle pleine sature le réseau mobile. Votre outil de contrôle doit fonctionner avec une liste téléchargée à l'avance et se synchroniser après.
- **Prévoyez le papier.** Téléphone déchargé, écran fissuré, code illisible sous une coque : gardez une file de secours avec recherche par nom.

## Le badge : le networking

Un QR code vCard sur le badge, à hauteur de poitrine, transforme chaque conversation en contact enregistré. C'est plus fiable que les cartes de visite ramassées par vingt, et cela évite le « je vous retrouve sur LinkedIn » qui n'arrive jamais.

## Le programme : la seule chose qui change tout le temps

Un programme imprimé est faux dès la première annulation. Un QR code sur l'affiche, sur le badge, sur le lutrin de chaque salle, qui ouvre le programme en ligne : vous mettez à jour, tout le monde voit la version juste.

Encodez une **URL stable** — jamais un lien qui contient la date ou le numéro de session, sinon vous réimprimez.

## Trois usages qu'on oublie

- **Les photos partagées.** Un code sur les tables du dîner qui ouvre un album collaboratif. Vous récupérez cent photos que vous n'auriez jamais eues.
- **L'évaluation.** Un code à la sortie de chaque atelier, tant que l'avis est frais.
- **Le plan et l'accès.** Un code d'itinéraire sur l'invitation, qui lance la navigation jusqu'à l'entrée exacte — pas jusqu'au centre du complexe.

## Les pièges du jour J

1. **Le code projeté trop tard.** Laissez-le à l'écran au moins trente secondes : les gens sortent leur téléphone, déverrouillent, ouvrent l'appareil photo.
2. **Le code derrière un plexiglas.** Les reflets tuent le scan. Testez sous l'éclairage réel du lieu.
3. **Le code trop haut ou trop bas.** Sur un kakémono, visez 1,40 m ; au sol, personne ne le voit.
4. **Un seul code pour tout.** Un code par usage, avec le texte qui l'explique. « Scannez » ne veut rien dire.

## Ce qu'il faut retenir

Billets et badges valent l'investissement dès la première édition. Le programme en ligne, lui, vous évite le pire scénario : trois cents personnes devant un papier qui n'est plus à jour.
