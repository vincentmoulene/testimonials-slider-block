QR codes walked into restaurants through the contactless-menu door. Which is a shame, because the menu is exactly the use case that gets done badly most often — while the other four pay off every single day.

## 1. The menu — as long as you do not send a PDF

A menu PDF on a phone is an A4 document you have to zoom, drag and zoom again. The customer gives up and asks for the paper menu: you have added a step, not removed a chore.

What works is a **plain web page**, readable without zooming, categories at the top. No app, no account, no cookie banner covering the screen. And keep a few paper menus: part of your clientele will never scan, and that is fine.

The critical part: **the menu address must never change**. If you reprint the table tents every time the menu does, you have lost. Publish at a stable URL (`your-restaurant.com/menu`) and change the content behind it.

## 2. Ordering and paying at the table

This is where the gain is real. On a busy terrace, a code per table that opens the order form cuts waiting time and the number of trips. Same for the bill — the customer pays and leaves instead of trying to catch a waiter's eye for ten minutes.

The code then has to identify the table (`/order?table=12`), so it is one code per table. Have them laminated and numbered on the back: a table tent moved to another table scrambles every order.

## 3. Reviews — the best return on effort

A happy customer almost never leaves a review, not out of unwillingness but because it takes too long: open Maps, find the right business, scroll, rate. A code that opens the star form directly removes all four steps.

The moment matters more than the placement: on the bill, at the end of the meal, while the customer is still there and still pleased. Not in an email three days later.

One absolute rule: **show the same code to everyone**. Filtering by expected rating breaks Google's policy and gets profiles suspended.

## 4. Guest Wi-Fi

A Wi-Fi code on the table tent saves you from dictating twenty characters ten times a service. Since iOS 11 and Android 10, the phone offers to join straight from the camera. Use your router's guest network, not the one the till is on.

## 5. Loyalty, booking, social media

A code on the loyalty card, on the flyer slipped into the takeaway bag, in the window so people can book when you are closed. Small volumes, but they cost nothing.

## The four mistakes that keep coming back

1. **A code that is too small.** At a table people scan from 30–40 cm: 3 cm wide minimum, 5 cm is better.
2. **A code on a dark or coloured background.** Scanners expect dark on light. A white rectangle behind the code is cheaper than a lost customer.
3. **No instruction at all.** Add one line: "Scan for the menu". Not everyone guesses.
4. **A code never tested on site.** Test it in your own room, in evening lighting, with an iPhone and an Android, at the real distance. Five minutes, once.

## The takeaway

The menu is the most visible use and the least profitable one. Reviews and table ordering are the ones that show up in the numbers. Start there.
