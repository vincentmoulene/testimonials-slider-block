An event is a place where several hundred people need the same information at the same time, on an unreliable network. That is exactly QR code territory — provided you plan for the day itself.

## The ticket: access control

One unique code per ticket, scanned at the door, marked as used. That is what stops the same ticket being resold to three people.

Two vital rules:

- **Plan for offline.** A full room saturates the mobile network. Your scanning tool must work from a list downloaded in advance and sync afterwards.
- **Plan for paper.** Flat battery, cracked screen, a code unreadable through a case: keep a fallback queue with search by name.

## The badge: networking

A vCard QR code on the badge, at chest height, turns every conversation into a saved contact. It beats collecting business cards by the twenty, and it avoids the "I'll find you on LinkedIn" that never happens.

## The programme: the one thing that always changes

A printed programme is wrong from the first cancellation. A QR code on the poster, on the badge, on the lectern of each room, opening the online programme: you update it, and everyone sees the correct version.

Encode a **stable URL** — never one containing the date or a session number, or you will be reprinting.

## Three uses people forget

- **Shared photos.** A code on the dinner tables opening a collaborative album. You get a hundred photos you would never have had.
- **Feedback.** A code at the exit of each workshop, while the opinion is fresh.
- **Access and directions.** A directions code on the invitation, starting the navigation to the exact entrance — not to the middle of the complex.

## Traps on the day

1. **A code projected too briefly.** Leave it on screen for at least thirty seconds: people take out a phone, unlock it, open the camera.
2. **A code behind plexiglass.** Reflections kill the scan. Test under the venue's real lighting.
3. **A code too high or too low.** On a roll-up banner, aim for 1.40 m; at floor level, nobody sees it.
4. **One code for everything.** One code per purpose, with a line explaining it. "Scan me" means nothing.

## The takeaway

Tickets and badges pay for themselves from the first edition. The online programme saves you from the worst case: three hundred people holding a piece of paper that is no longer true.
