Ein Verkaufsschild nennt eine Telefonnummer. Vorbeigehende notieren sie — oder eben nicht. Mit einem QR-Code sehen sie Fotos, Preis, Fläche und Energieausweis, bevor sie anrufen. Und wenn sie anrufen, wissen sie bereits, was sie wollen.

## Das Schild: qualifizieren vor dem ersten Anruf

Der Code muss **das Exposé dieses Objekts** öffnen, nicht die Website des Maklerbüros. Fotos, Preis, Fläche, Gutachten, Grundriss. Wer danach anruft, hat den ersten Filter selbst passiert.

Praktische Randbedingungen eines Schilds:

- Gescannt wird vom Gehweg, oft aus dem haltenden Auto: mindestens **15 cm Breite** für einen Scan aus 1,5 m, mehr bei hoch angebrachten Schildern.
- Das Schild steht monatelang draußen: UV-beständiger Druck, sonst verblasst der Kontrast und der Code stirbt.
- Planen Sie den Fall „verkauft": Die Seite sollte das anzeigen und ähnliche Objekte vorschlagen, statt einen 404 zu liefern.

## Das Schaufenster des Büros

Der eigentliche Moment ist der Sonntag: Das Büro ist zu, geschaut wird trotzdem. Ein Code je Exposé im Fenster oder ein Sammelcode zu den Objekten im Viertel erreicht ein Publikum, das sonst gar nichts getan hätte.

## Die Mietbewerbung

Ein Code im Exposé, der die Liste der einzureichenden Unterlagen und das Bewerbungsformular öffnet. Sie bekommen vollständige Mappen statt zwanzig Mails mit fehlenden Anhängen.

## Übergabe und Verwaltung

Unspektakulär, sehr nützlich:

- Ein Code im Zähler- oder Technikraum, der das Geräteblatt, das Datum der letzten Wartung und die Nummer der Firma öffnet.
- Ein Code in der Ferienwohnung, der die Gästemappe öffnet.
- Ein Code am schwarzen Brett der Eigentümergemeinschaft zu den Protokollen der letzten Versammlung.

## Drei Fehler, die Kontakte kosten

1. **Auf die Startseite verlinken.** Gesucht war *dieses* Objekt; niemand durchsucht dafür zweihundert Exposés.
2. **Eine URL mit interner Referenz codieren**, etwa `?ref=A12345&session=…`. Sie ändert sich bei der nächsten Softwaremigration, und der gedruckte Code stirbt mit.
3. **Die Messung vergessen.** Hängen Sie `?utm_source=schild` an: Nach einem Quartal wissen Sie, ob die Schilder ihr Geld wert sind.

## Was bleibt

In der Immobilienbranche verkauft ein QR-Code nichts: Er entfernt die Verzögerung zwischen Interesse und Information. Und genau diese Verzögerung kostet in diesem Geschäft die Kontakte.
