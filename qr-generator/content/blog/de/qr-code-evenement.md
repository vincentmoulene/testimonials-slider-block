Eine Veranstaltung ist ein Ort, an dem mehrere hundert Menschen gleichzeitig dieselbe Information brauchen — bei unzuverlässigem Netz. Genau das ist QR-Code-Terrain, sofern man den Tag selbst mitdenkt.

## Das Ticket: die Einlasskontrolle

Ein eindeutiger Code je Ticket, am Eingang gescannt, als benutzt markiert. Das verhindert, dass dasselbe Ticket dreimal weiterverkauft wird.

Zwei überlebenswichtige Regeln:

- **Planen Sie offline.** Ein voller Saal legt das Mobilnetz lahm. Ihr Scan-Werkzeug muss mit einer vorab geladenen Liste arbeiten und später synchronisieren.
- **Planen Sie Papier ein.** Leerer Akku, gesprungenes Display, ein Code, der durch die Hülle nicht lesbar ist: Halten Sie eine Ersatzschlange mit Namenssuche bereit.

## Das Badge: das Networking

Ein vCard-QR-Code auf dem Badge, auf Brusthöhe, macht aus jedem Gespräch einen gespeicherten Kontakt. Das ist verlässlicher als zwanzig eingesammelte Visitenkarten und erspart das „Ich finde Sie auf LinkedIn", das nie passiert.

## Das Programm: das Einzige, was sich immer ändert

Ein gedrucktes Programm ist ab der ersten Absage falsch. Ein QR-Code auf dem Plakat, auf dem Badge, auf dem Pult jedes Saals, der das Onlineprogramm öffnet: Sie aktualisieren, alle sehen die richtige Fassung.

Codieren Sie eine **feste URL** — nie eine mit Datum oder Sessionnummer, sonst drucken Sie nach.

## Drei vergessene Anwendungen

- **Geteilte Fotos.** Ein Code auf den Tischen des Abendessens öffnet ein gemeinsames Album. Sie bekommen hundert Fotos, die Sie sonst nie hätten.
- **Feedback.** Ein Code am Ausgang jedes Workshops, solange der Eindruck frisch ist.
- **Anfahrt.** Ein Routen-Code auf der Einladung, der die Navigation zum genauen Eingang startet — nicht zur Mitte des Geländes.

## Fallen am Veranstaltungstag

1. **Ein zu kurz gezeigter Code.** Mindestens dreißig Sekunden stehen lassen: Telefon holen, entsperren, Kamera öffnen.
2. **Ein Code hinter Plexiglas.** Spiegelungen zerstören den Scan. Unter der echten Beleuchtung testen.
3. **Ein zu hoch oder zu tief hängender Code.** Auf einem Roll-up 1,40 m anpeilen; am Boden sieht ihn niemand.
4. **Ein Code für alles.** Ein Code je Zweck, mit einer erklärenden Zeile. „Scannen" sagt nichts.

## Was bleibt

Tickets und Badges rechnen sich ab der ersten Ausgabe. Das Onlineprogramm erspart Ihnen den schlimmsten Fall: dreihundert Menschen mit einem Zettel, der nicht mehr stimmt.
